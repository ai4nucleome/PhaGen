PhaGen

Overview

PhaGen is a 150M-parameter model for generating and analyzing bacteriophage DNA. It learns by reconstructing masked DNA and generates sequences by filling masked positions over multiple steps.

The same pretrained model provides sequence embeddings and masked-region scores for downstream prediction. The repository includes model code, usage examples, and training code based on VeOmni.

Quick start

Install PhaGen from the repository root. The examples support a downloaded checkpoint or a local model directory.

Python 3.10+ · PyTorch 2.5 · Transformers 4.54.1

git clone https://github.com/ai4nucleome/PhaGen.git
cd PhaGen
python -m pip install -e .

See the GitHub README for generation and embedding examples.
